# Machine Learning Terms and Metrics

A beginner-friendly collection of essential Machine Learning concepts, terminology, evaluation metrics, and practical examples using Python.

## Overview

This repository helps students and aspiring Machine Learning Engineers understand important ML concepts and evaluation techniques through explanations and Jupyter Notebook examples.

## Topics Covered

- Machine Learning Fundamentals
- Supervised and Unsupervised Learning
- Classification and Regression
- Data Preprocessing
- Feature Scaling and Standardization
- Model Training and Testing
- Classification Metrics
- Regression Metrics
- Model Evaluation Techniques
- Python and Scikit-learn

## Evaluation Metrics

### Classification Metrics
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix
- ROC-AUC

### Regression Metrics
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R-squared (R²)

## Technologies Used

- Python
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Repository Contents

- `Machine Learning terms and metrics.ipynb` — Notebook containing Machine Learning terminology and metric explanations.

## Who Is This For?

- Students learning Machine Learning
- Beginners in Data Science
- Aspiring Machine Learning Engineers
- Developers preparing for AI/ML interviews
